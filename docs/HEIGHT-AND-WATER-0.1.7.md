# 0.1.7 高度与水系

本次新世界的主世界建造范围为 Y=-64..511，海平面为 Y=40，原有高山的顶峰提高至约 Y=480。BDS 与 Windows LL 共用生成实现；Android 保持封档。

## 世界与生成范围

高度行为包使用主世界 `minecraft:dimension_bounds` (-64,512) 与 `minecraft:generation` 的 `void`，运行时同时接管 VoidGenerator 和原来的 FlatWorldGenerator。512 为排他上界。每个区块使用 576 格生成列和 36 个群系子区块，KW2 缓存按世界配方校验实际列高，不能混读旧 384 格缓存。

新世界持久保存 buildMaxYExclusive=512、generatedMaxYExclusive=512。缺失字段的旧世界继续按320处理；仅更新DLL不会改写旧存档生成配方。元数据、原生维度范围、原生配方不一致时明确拒绝运行。Windows 新建世界在启动本地服务前安装并注册高度包，再核验实际主世界范围。

## 山地与水系

原高程96以下保持；96以上逐渐抬升，原高程240附近映射至480，峰顶用连续曲线收尾，避免硬裁切形成一片平顶。巨木森林保留保护区过渡。山地变化不整体平移海岸或山脚；山体上方保留建造余量。

海岸、河口、海洋生态、蘑菇岛及海岸结构选址采用配方海面。山间河源与湖泊的搜索上限扩展到新山地范围；仍使用实际地形与下游汇流约束。既有地下洞穴位图继续限定原高度范围；本次没有将洞穴形状整体拉伸。

## 检查范围

离线测试覆盖旧配方兼容、576格列的编码和填充、两端不同内存布局、海岸水位、蘑菇岛隔海边界、区域水路连接、真实高山样本和打包世界完整性。

## 地形采样参考点

新BDS测试种子9：峰值样本 (8192,-7936) 地面Y486；附近湖泊 (7872,-8640) 地面Y348、水面Y352。峰周边3×3区域的26条抽样下游水路均有生产surface水体支撑。种子5对应峰值样本为Y481。这些坐标来自离线地形采样。
