# 群系与结构传送（0.1.6 / BDS 1.0.48）

`/karma` 查看当前全部群系和结构目录。沿用 31 个群系/特殊地形编号 101..131，以及 20 组结构的 45 个地点编号 1..45；尚未找到坐标的条目仍显示编号、名称和搜索状态。搜索继续使用当前世界与种子，已找到的地点不重新编号。

`/karma tp <序号> <模式>` 两个参数都必须填写。模式 `1` 是创造，`0` 是观察者；不接受其他数字或地形名称。例：`/karma tp 128 1` 以创造模式前往蘑菇岛，`/karma tp 128 0` 以观察者模式前往。模式、编号或坐标无效时，不改变玩家位置、模式或返回记录。

`/karma back` 返回第一次测试传送前的位置、维度和模式。连续测试传送不会覆盖这一返回记录。玩家退出或插件正常禁用时仍恢复测试前状态。

玩家进入时显示蓝色（`§9`）更新说明：128 蘑菇岛、115 恶地、129 侵蚀恶地、130 恶地高原、131 繁茂恶地高原，每项同时显示更新内容。说明标明最近地形更新来自 0.1.5；0.1.6 没有更改生成算法。目录与提示直接发送给玩家，不依赖 `sendcommandfeedback`。

此命令由 BDS 的测试辅助功能提供，需启用已有 `testTeleport` 配置。Windows 客户端连接该 BDS 时使用相同命令；Windows LL 单机模组不额外注册此测试命令。本次 Windows 0.1.6 同步源码与版本、重新构建并留存，生成规则与 0.1.5 相同，Android 保持封档。

验证分层：宿主回归测试覆盖 76 个编号、无效编号、模式边界及蓝色更新文案；BDS/Windows SDK 构建与包检查验证交付。
