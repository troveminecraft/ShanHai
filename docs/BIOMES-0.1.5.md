# 山&海 0.1.5：蘑菇岛与恶地

> 此页记录 0.1.5 历史行为。当前传送方式已改为编号和模式，见 [0.1.6 命令说明](KARMA-COMMANDS.md)。

本版本供用户游戏内验收。离线边界检查、编译和服务启动不代表游戏内验收通过。

新配方启用 `config.completedBiomes=1`。旧配方不包含该开关，因此保持原有地形和材质；新方块与群系只追加编号，不重新排列旧编号。运行时按旧内核版本验证 168/25 项旧表，按新内核验证 178/29 项新表，不接受任意截断或混合表。

蘑菇岛从海洋候选中选择，剔除冻结、湖泊和特殊地形候选。岛体有低丘、菌丝土、红褐小蘑菇和巨型蘑菇，周围保留海洋带。岛岸不替换成沙滩、河流、沼泽或其他陆地群系。候选粗采样只负责选址；最终逐列的海洋带负责保证隔离，测试按方块检查最终蘑菇岛边缘的四邻接群系。

恶地补充暖干气候筛选、红沙与红砂岩支撑层、种子决定的 192 层陶瓦色带及缓慢横向偏移、侵蚀恶地柱、高原和繁茂高原地表。额外金矿条件覆盖新增恶地变体，沿用原有石质矿脉替换规则。原版群系标识继续用于原生群系属性和生物生成。

对照依据是 Mojang 的 [mesa 定义](https://github.com/Mojang/bedrock-samples/blob/main/behavior_pack/biomes/mesa.biome.json)、同目录的 `mesa_bryce`、`mesa_plateau` 和 `mesa_plateau_stone` 定义，以及当前 SDK 的 `MesaSurfaceBuilder` 数据结构。保留原版材料、色带、柱状侵蚀和森林高原的生成语义；世界形状、噪声和随机序列适配山&海海平面 Y=31，**不是相同种子的原版逐方块复刻**。

共享地形、材质、植被和契约同时用于 BDS 与 Windows LL。Android 不更新。BDS 测试辅助命令恢复名称选择：`/karma tp 蘑菇岛`、`/karma tp 恶地`、`/karma tp 侵蚀恶地`、`/karma tp 恶地高原`、`/karma tp 繁茂恶地高原`。英文群系名称和旧编号也有效。无参数默认展示本版地点，`/karma tp all` 展示完整目录，`/karma back` 返回测试前的位置与模式。该测试命令原本属于 BDS 适配器，不作为 Windows 游戏内命令交付。

待游戏内确认：菌丝土显示、巨型蘑菇完整性和刷新规则；整圈岛岸、流体更新与海面连接；恶地色带、侵蚀柱和高原观感；按名称传送的提示与返回模式。生成变化需要新区域或新世界，本次 BDS 使用新种子，旧世界保留。
