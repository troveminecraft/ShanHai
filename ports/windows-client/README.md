# 山&海 0.2.3

Minecraft 基岩版 Windows 客户端地形生成模组。

## 安装

需要 Minecraft for Windows **1.26.20.04**、LeviLamina **26.20.7 客户端版**，以及支持 AVX2 的 Windows x64 电脑。

1. 保存并完全退出 Minecraft。
2. 在 LeviLauncher 的对应实例中打开模组管理，导入 `ShanHai-Windows-0.2.3.zip`。
3. 确认 `karma-worldgen-client` 已启用，再启动游戏。
4. 创建普通新世界，可自行填写种子；不要选择超平坦。

ZIP 包含完整种子生成运行依赖，无需另装 Python 或 Node.js。不要只复制 DLL。
内部目录和标识 `karma-worldgen-client` 用于保持存档兼容，显示名称为“山&海”。
已有同标识模组时，请替换原安装，避免同时安装两份 DLL。

## 使用与反馈

0.2.3 是公开测试版本，结构与复杂坡地的衔接仍可能出现异常。更新前备份世界。
反馈时请提供版本、种子、坐标、截图及复现过程。

0.2.3 新世界海平面为 Y=100，山峰顶峰约 Y=480，主世界建造范围为 Y=-64..511。随世界附带高度行为包，请保留该包。0.1.13 及以前支持的配方保留原规则；0.1.14/0.1.15 实验世界需使用留存的对应版本，不静默迁移。

地形随探索按区域生成，不设固定测试边界。已有原版区块不会自动改造。
模组世界需要保持启用本模组后继续游玩；不支持卸载后无缝切回原版生成。

本包不适用于 BDS、Android、Java 版或其他 Minecraft 构建。原版结构模板从本机游戏读取，包内不包含游戏本体。

本版针对单人世界加载失败：新建世界时同步注册高度包来源及原生内存包选择，在启动生成器前检查实际服务器包栈；原生初始化失败后不提前释放仍被排队任务使用的会话。地形配方沿用 0.2.1。游戏内新建、加载和重进由玩家验收。

若仍失败，请保留 `diagnostics/world-startup.json`、`diagnostics/world-error.txt`、创建任务的 `handoff.jsonl` 和世界 `karma/fatal-runtime.json`，反馈失败发生阶段。启动诊断不代表游戏内验收通过。

0.2.3：扩展主世界普通云与灵动视效云层目标 Y500（共用云网格提取入口）。补块排除未请求的视距边缘，仅恢复阶段停滞或内部缺口；world-session.json 增加各阶段耗时和云层路径计数。整体森林提速与缺块修复尚待游戏内确认。
