# mountains&seas · 山&海 0.4.0

作者：**peakarma**。0.4.0 仍在开发中。最新的 Windows 26.51 修订使用内核 **2.223**；留存的 Windows 26.20 包使用 **2.219**，两者不包含完全相同的改动。

| Minecraft Windows | LeviLamina 客户端 | 安装包 |
|---|---|---|
| 1.26.51.01 | 26.51.9 | `ShanHai-Windows-0.4.0.zip` |
| 1.26.20.04 | 26.20.7 | `ShanHai-Windows-26.20-0.4.0.zip` |

需要 Windows x64 和支持 AVX2 的 CPU。保存并完全退出 Minecraft 后，在 LeviLauncher 对应实例导入匹配 ZIP 并启用 mountains&seas。运行依赖已包含在包内。旧模组文件夹备份到 `mods` 之外，保留配置和已有存档，避免同时启用两份模组。

创建普通世界以启用模组地形。海平面为 Y100，建造范围为 Y-64..511。旧世界保持保存的配方及方块，新配方的盆地、樱花树等内容不会自动覆盖旧世界。26.51 专属森林世界不能在 26.20 打开。

`/locate biome peakarma:roofed_forest` 等命令搜索山海实际群系，说明默认英文，中文游戏语言下使用中文。区域目标搜索 16,384 格，其余目标搜索 8,192 格；45 秒时限内未完成会显示不完整。查询不请求世界区块。

部分地形高度层不可见、靠近后恢复的问题仍在调查。详细记录按会话保存，保留最近三次可识别会话；退出游戏后运行 `collect-diagnostics.cmd` 生成本地诊断包，不会自动上传。详见包内 `LOADING_DIAGNOSTICS.md`。

派生缓存采用无损压缩和独立预算；探索新区域仍会增加世界存档体积。原创代码使用 MIT，第三方许可见 `THIRD_PARTY_NOTICES.md`。
