# mountains&seas · 山&海 0.4.0

Minecraft 基岩版 Windows 地形与结构生成模组。作者：peakarma。

## 兼容版本

| Minecraft for Windows | LeviLamina client | 安装包 |
|---|---|---|
| 1.26.51.01 | 26.51.9 | `ShanHai-Windows-0.4.0.zip` |
| 1.26.20.04 | 26.20.7 | `ShanHai-Windows-26.20-0.4.0.zip` |

需要 Windows x64 和支持 AVX2 的 CPU。请选择对应游戏版本的 ZIP。

## 安装与升级

保存并完全退出 Minecraft，在 LeviLauncher 对应实例导入完整 ZIP，启用 **mountains&seas**。创建普通新世界并填写种子；不要选择超平坦。ZIP 包含 Python 和 Node.js 依赖。

从旧 `karma-worldgen-client` 条目升级时，将旧文件夹备份到 `mods` 之外后导入新包，保留 `client-config.json` 和已有存档；不要同时启用两份模组。已生成的方块保留，原版世界不会自动转换。

## 0.4.0 更新

新世界新增黑森林、苍白之园、樱花树林和红树林沼泽，两套游戏版本均支持；1.26.51.01 另有斑驳森林，包含彩色杨树、倒木和层架蘑菇。森林按现有气候、坡度与海拔选择位置，少量大型树木仅在局部出现。

苍白橡树生成原生自然嘎枝之心；红树林根保留次方块层的水。林地府邸要求真实黑森林。`/karma` 新增 141–144，26.51 额外提供 145；原编号和可选传送模式保持不变。

新世界使用 **2.219** 配方和固定的游戏能力配置，旧世界继续使用保存的配方与地形，包括 2.217。包含 26.51 专属森林内容的世界不能在 26.20 打开。海平面保持 Y100，建造范围保持 Y-64..511。同时修复切换世界时复用错误群系表，以及中文路径下的种子准备问题。

密集地形、大视距和原生结构处理仍可能带来加载延迟。嘎枝之心的夜间行为及新增森林的保存、重载行为仍需扩大各兼容版本的覆盖。

## 诊断

日志按世界会话保存，包含后台心跳、正在执行的任务及丛林缓存统计。退出游戏后运行模组目录的 `collect-diagnostics.cmd` 可生成本地诊断包；不会自动上传。详见 `LOADING_DIAGNOSTICS.md`。
