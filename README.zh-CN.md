# 山&海 · mountains&seas

Minecraft 基岩版 Windows 地形与结构生成模组。作者：**peakarma**。版本 **0.4.0**。[下载](https://github.com/troveminecraft/ShanHai/releases/tag/0.4.0)。

[English](README.md) · 简体中文

海平面为 **Y100**，建造范围为 **Y-64..511**。山脉、盆地、高原、江河、湖泊、瀑布、火山和超级冰川使用同一套种子生成规则。盆地是包含内部丘陵、起伏和河谷的地形，不等同于一个群系。

当前 26.51 修订使用 **2.225** 内核：巨型樱花树的主干和根部收细，中上层分枝与花簇更密集，树冠侧面呈中央隆起、两侧渐低的轮廓，保留弯曲分枝和簇间空隙；入湖河床连续过渡进湖底，消除交界处突起的沙墙。保留宽阔内陆盆地、拔高的小樱花树、大岩石及减少的冰雪平原倒木；Y200～300 优先形成更大的樱花林。废弃传送门按实际结构占地避让植被，巨树根部与建筑相交时整棵避让。

黑森林和苍白森林具有连片树冠、40～50 格高的粗壮树干、不规则树洞和自然洞底；树洞内南瓜灯概率为 66%，苍白树洞内自然嘎吱之心概率为 11%。树根使用全树皮木块并附着荧光地衣。红树林位于温暖内陆盆地，树根落在浅水泥地。26.51 还包含原生斑驳森林内容。

村庄以早期建筑数量的六倍为目标，在紧凑不规则地块间连接道路，保留原版建筑模板及原规模的初始村民和动物。超级冰川崖壁覆薄冰，草丛和蕨类可通过原生次方块层与薄雪共存。

## 群系查询

山海存档使用 `/locate biome peakarma:roofed_forest` 等名称检索真实生成规则。说明默认英文，中文游戏语言下使用中文。普通存档保留原版命令。

冰川、火山、樱花林、红树林和内陆盆地优先检查区域候选，搜索范围为 16,384 格；其他目标为 8,192 格。结果经过完整配方复核。查询使用独立后台线程，不请求生成区块；返回附近的匹配地点，不保证是全范围最近一格。45 秒工作时限内未查完会显示结果不完整。

两份 0.4.0 包包含不同内核修订。最新 26.51 改动未包含在留存的 26.20 包中。BDS 单独支持 **1.26.20.5 / LeviLamina 26.20.7**，本次 26.51 修订不更新 BDS。安卓封档，不支持其他游戏或加载器构建。

保存并完全退出 Minecraft 后，在 LeviLauncher 对应实例导入匹配 ZIP，启用 mountains&seas，创建普通新世界。运行依赖已随包提供。升级时将旧模组目录备份到 `mods` 之外，保留配置及存档，避免启用两份模组。

旧世界保留已保存的配方与方块；更换 DLL 不会重新绘制已有世界。新的生成特征需要新配方。含 26.51 专属内容的世界不能在 26.20 打开。

## 存储与限制

派生地形缓存采用无损压缩，每个世界配方由后台管理约 512 MiB 预算，与存档方块、结构和玩家数据分开。详细诊断保留最近三次可识别会话。持续探索仍会增加世界体积。

“上方树叶可见、下方地形部分不可见，靠近后恢复”的问题列入 0.4.x 后续维护，0.4.0 中仍可能出现。密集地形、大视距、探索新区域和原生结构处理仍可能造成加载延迟。详见[已知问题](docs/KNOWN_ISSUES.md)、[加载诊断](docs/LOADING_DIAGNOSTICS.md)、[森林兼容](docs/FOREST_COMPATIBILITY.md)和[构建说明](docs/DEVELOPMENT.md)。
