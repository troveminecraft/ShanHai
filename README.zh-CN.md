# 山&海 · mountains&seas 0.4.0

超级冰川的外露崖壁增加薄冰层；草丛和蕨类通过原生次方块层与顶层雪共存。新地形采用 **2.222** 配方，旧世界继续保留已保存的生成规则。

派生地形缓存采用无损压缩，每个世界配方由后台管理约 512 MiB 的缓存预算，兼容读取旧缓存。这些可重建缓存与存档方块、玩家数据和结构分开。详细加载诊断只保留最近三次可识别会话。持续探索新区域仍会增加世界体积。

修复弯曲悬崖边缘的细长尖突：崖面直接衔接两侧地形，保留落差、弯曲轮廓和两端过渡。旧世界继续沿用已保存的悬崖配方。

26.51 新世界减少高悬崖，部分崖壁生长向外伸展的小树。山坡增加浅层差异侵蚀纹理，同时保留平滑岩穹。黑森林和苍白森林的树干错落分布，树洞不再对称成排，洞底保留自然地面，树根使用全树皮木块，嘎吱之心通过连续木柱连接地面。大村庄保留建筑数量，改用紧凑的不规则地块与连通道路。群系检索先筛选轻量候选，再核验真实地表；查询缓存有独立上限，不进入区块生成队列。

[English](README.md) · 简体中文

BDS 地形 **1.0.63**、结构 **1.0.78**，Windows **0.4.0**。

修复持久树叶与旧方块表条目重复映射导致的加载世界退出，保持存档配方和地形兼容。山海存档中的 `/locate biome` 使用 `peakarma:` 群系候选，例如 `peakarma:roofed_forest`（黑森林）和 `peakarma:super_glacier`（超级冰川），覆雪变种单独检索。Windows 命令候选带有群系说明；说明与查询消息默认英文，玩家游戏语言为中文时使用中文。

黑森林和苍白森林改为连片共用树冠，支撑树高 40～50 格、树干半径 5～7 格；拱形树洞内有 66% 概率生成南瓜灯，苍白树洞另有 11% 概率生成自然嘎吱之心，树根表面附着荧光地衣。樱花林连片主要跨度 160～480 格，中心巨树约高 70 格、树干半径 10～20 格。缓流河段可分岔并在下游汇流，分支仍检查河岸封闭。村庄以原建筑数量的六倍为目标，原版建筑集中于不规则地块并以道路连接，初始村民和动物维持原规模，避免将实体 AI 开销一起放大；不适合的地形或超过村庄占地边界的布局会被拒绝。

新世界新增黑森林、苍白之园、樱花树林和红树林沼泽，两套游戏版本均支持；1.26.51.01 另有斑驳森林，包含彩色杨树、倒木和层架蘑菇。森林按现有气候、坡度与海拔选择位置。

0.4.0 仍在开发中，之前的发布已撤回。新的红树林规则限定在温暖、湿润的内陆盆地，连片主要跨度至少 160 格，树木加密且根部落在浅水中的泥地上。`/locate biome` 在山海存档中后台检索该世界的冻结配方，普通存档保留原版行为。

苍白橡树生成原生自然嘎枝之心；红树林根保留次方块层的水。林地府邸要求真实黑森林。`/karma` 新增 141–144，26.51 额外提供 145；原编号和可选传送模式保持不变。

26.51 新世界使用 **2.222** 配方和固定的游戏能力配置，旧世界继续使用保存的配方与地形，包括 2.217。包含 26.51 专属森林内容的世界不能在 26.20 打开。海平面保持 Y100，建造范围保持 Y-64..511。同时修复切换世界时复用错误群系表，以及中文路径下的种子准备问题。

密集地形、大视距和原生结构处理仍可能带来加载延迟。嘎枝之心的夜间行为及新增森林的保存、重载行为仍需扩大各兼容版本的覆盖。
